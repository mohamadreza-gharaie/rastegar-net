# رستگار نت — سامانهٔ آموزش آنلاین

ساخته‌شده با HTML، CSS، جاوااسکریپت و Python (Flask + Flask-SocketIO + WebRTC).

## اجرا
1. Python 3.9 یا بالاتر نصب باشد.
2. **ویندوز:** روی `run.bat` دابل‌کلیک کنید. **لینوکس/مک:** `./run.sh`
   (یا دستی: `pip install -r requirements.txt` و سپس `SSL_ADHOC=1 python app.py`)
3. مرورگر را باز کنید: `https://localhost:5000`
   (چون گواهی خودامضاست، مرورگر هشدار می‌دهد؛ «ادامه / Advanced → Proceed» را بزنید.)

> **چرا HTTPS؟** مرورگرها دوربین، میکروفن و اشتراک صفحه را فقط روی `localhost` یا `https` اجازه می‌دهند.
> اگر دانش‌آموزان از طریق IP شبکه (مثلاً `https://192.168.1.10:5000`) وارد می‌شوند، حتماً HTTPS لازم است.
> برای استفادهٔ واقعی روی اینترنت، دامنه و گواهی معتبر (مثل Let's Encrypt) بگیرید و با `SSL_CERT` و `SSL_KEY` یا پشت nginx (با `TRUST_PROXY=1`) اجرا کنید.

## انتشار روی Render.com
راهنمای کامل مرحله‌به‌مرحله در فایل `DEPLOY_RENDER.md` و تنظیمات آماده در `render.yaml` است.

## بخش مدیریت
- آدرس: `/admin` (لینک «ورود مدیران و معلمان» در صفحهٔ اول)
- ورود فقط با رمز عبور: `Rastegar12net21`
- تغییر رمز: متغیر محیطی `ADMIN_PASSWORD` (یا مقدار پیش‌فرض در `config.py`)

### امکانات پنل
- **کلاس‌ها:** وضعیت زندهٔ ۹ کلاس (۷۰۱، ۷۰۲، ۷۰۳، ۸۰۱، ۸۰۲، ۸۰۳، ۹۰۱، ۹۰۲، ۹۰۳) و کلیدهای باز/بستن میکروفن، دوربین، چت و اشتراک صفحهٔ دانش‌آموزان.
- **کاربران:** افزودن دانش‌آموز به هر کلاس با نام و رمز مخصوص (تکی یا گروهی)، تغییر رمز/نام، حذف، اخراج و رفع اخراج. بدون رمز ثبت‌شده، ورود به کلاس ممکن نیست.
- **حضور و غیاب:** فهرست زندهٔ حاضران و غایبان هر کلاس + گزارش هر روز (زمان ورود و مدت حضور).

## داخل کلاس (برای معلم)
- ورود معلم: از پنل مدیریت دکمهٔ «ورود به کلاس» (رمز دوباره لازم نیست).
- تب «کنترل کلاس»: کلید کل کلاس برای میکروفن/دوربین/چت/اشتراک صفحه + «بستن میکروفن همه» و «باز کردن میکروفن همه» + پاک کردن گفتگو.
- تب «حاضرین و غایبین»: برای هر دانش‌آموز جدا میکروفن، دوربین، چت و اشتراک صفحه را باز/بسته کنید، یا او را **اخراج** کنید (۳۰ دقیقه امکان ورود ندارد؛ «رفع اخراج» هم ممکن است).
- معلم همیشه می‌تواند صحبت کند، گفتگو بنویسد و صفحهٔ لپ‌تاپ خود را زنده نمایش دهد. اشتراک صفحه برای دانش‌آموزان به‌طور پیش‌فرض بسته است و معلم می‌تواند بازش کند.

## تنظیمات (متغیر محیطی یا `config.py`)
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `ADMIN_PASSWORD` | Rastegar12net21 | رمز پنل مدیریت |
| `KICK_MINUTES` | 30 | مدت محرومیت پس از اخراج |
| `PORT` | 5000 | پورت |
| `SSL_ADHOC` | 1 در run.sh/run.bat | HTTPS با گواهی خودامضا |
| `SSL_CERT` / `SSL_KEY` | — | گواهی واقعی |
| `TURN_URL` / `TURN_USER` / `TURN_PASS` | — | سرور TURN (پایین را ببینید) |

## نکتهٔ مهم دربارهٔ تماس گروهی
تماس تصویری/صوتی به‌صورت WebRTC «مش» است (هر نفر مستقیم به هر نفر وصل می‌شود)؛ برای کلاس‌های تا حدود **۸ تا ۱۲ نفر** مناسب است.
برای کلاس‌های شلوغ‌تر به یک سرور رسانه (SFU مثل LiveKit یا mediasoup) نیاز دارید. اگر بعضی دانش‌آموزان به‌خاطر اینترنت‌های سخت (NAT) به تصویر وصل نشدند، یک سرور TURN (مثل coturn) راه بیندازید و متغیرهای `TURN_*` را تنظیم کنید.
به‌طور پیش‌فرض از سرور STUN عمومی گوگل استفاده می‌شود؛ روی شبکهٔ محلی (LAN) بدون اینترنت هم تماس مستقیم کار می‌کند.

## ساختار پروژه
```
app.py            سرور Flask و Socket.IO (ورود، اتاق‌ها، اخراج، دسترسی‌ها، حضور و غیاب)
config.py         تنظیمات
templates/        صفحه‌های HTML
static/css        استایل
static/js         class.js (تماس و گفتگو)، admin.js (پنل)، ...
instance/         پایگاه داده SQLite و کلید نشست (خودکار ساخته می‌شود)
```
پایگاه داده `instance/rastegar.db` است؛ برای پشتیبان‌گیری همین فایل را کپی کنید.
